# E-Commerce Sales Performance Dashboard

## Project Overview

This project analyzes e-commerce sales data using Tableau to explore revenue performance, customer ratings, product categories, and payment methods.

The goal is to create an interactive dashboard that helps users understand sales trends and compare performance across different business segments.

## Live Dashboard

[View Interactive Tableau Dashboard](https://public.tableau.com/app/profile/oner.oymak/viz/Book1_17880675702980/E-CommerceSalesPerformanceDashboard)

## Tools Used

- Tableau Public
- CSV Dataset
- Data Visualization
- Business Intelligence

## Key Performance Indicators (KPIs)

- **Total Revenue:** 5.11M
- **Gross Sales:** 6.24M
- **Total Orders:** 5,000
- **Average Customer Rating:** 2.97

## Dashboard Features

- Monthly Revenue Trend
- Revenue by Region
- Revenue by Product Category
- Revenue by Payment Method
- Customer Rating by Category
- Quantity by Product Category
- Interactive Region and Product Category filters

## Dataset

The dashboard uses an e-commerce dataset containing
5,000 records with information about orders, customers,
products, sales, and customer ratings.
